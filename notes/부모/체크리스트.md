# 부모 스킬 — 시스템 정합성 자가점검 체크리스트

본 체크리스트는 부모 스킬이 전체 사이클 종료 시(또는 단독 모드 종료 시) 자체 점검하는 8개 항목.
모두 ✅ 통과해야 사용자에게 종합 결과 안내.

═══════════════════════
1. 시스템 정합성 점검 (8)
═══════════════════════

| # | 점검 항목 | ✅ |
|---|---|---|
| 1 | 1번·2번·3번 .md 모두 생성됨 (전체 모드) 또는 호출 모드의 산출물 생성됨 | ☐ |
| 2 | 명명 규칙 준수 — `AI자동화_{타입}_{이름}_{날짜}.md` (타입 = 진단보고서·설계도·개발지침서) | ☐ |
| 3 | 설계도 frontmatter에 진단 파일명 명시 | ☐ |
| 4 | 지침서 frontmatter에 진단·설계 파일명 둘 다 명시 + 설계도 버전 | ☐ |
| 5 | 모든 산출물에 inline 매핑 (출처 § N 한 줄 표시) 적용 | ☐ |
| 6 | WebSearch 검색일 푸터 모두 명시 (산출물 간 날짜 일관성) | ☐ |
| 7 | 사용자 게이트 모두 통과 — 단계 사이 Y/N 확인 누락 X | ☐ |
| 8 | 산출물 위치·요약 사용자에게 안내 완료 | ☐ |

═══════════════════════
2. 통과·실패 처리
═══════════════════════

[통과 — 8개 항목 모두 ✅]
→ 종합 결과 안내 (3개 파일 경로·요약·총 작업 시간 등)
→ "전체 사이클 완료" 메시지로 종료

[실패 — 일부 ❌]
- 산출물 누락 → 누락 단계 다시 호출 또는 사용자에게 보고
- 명명 규칙 위반 → 해당 산출물 재명명 (서브 스킬 재호출)
- frontmatter 상호참조 누락 → 해당 서브 스킬 재호출 (frontmatter 보강)
- inline 매핑 누락 → 서브 스킬 자가점검에서 잡혀야 함 (감사 보고)
- WebSearch 검색일 누락 → 서브 스킬 재실행
- 사용자 게이트 누락 → 부모 흐름 자체 결함 — 보고서 작성 후 재시작

═══════════════════════
3. 부모 스킬은 .md 산출물 직접 생성 X
═══════════════════════

본 체크리스트는 부모가 시스템 차원에서 일관성을 검증하는 도구.
부모 스킬 자체는 사용자에게 안내·게이트만 담당하며 .md 파일 생성은 모두 서브 스킬이 수행.
