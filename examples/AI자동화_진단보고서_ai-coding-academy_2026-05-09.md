## 🎯 2. 자동화 요청 내용

### 업무 설명
```
넥스트AI아카데미 교육 운영팀(박지훈 팀장)이 CEO 대상 AI 코딩 전문가 양성 과정을 운영 중.
수강생은 직접 코딩하거나 외주 대행 의뢰 또는 자기 회사 개발자와 협업하는 방향으로 활용.
코스는 3단계 — 1단계(6시간/20만원) / 2단계(12시간/40만원) / 3단계(24시간/100만원).
수료 시 자격증 발급. 현장 강의 + 화상 강의 병행.
현재는 수강 신청부터 자격증까지 엑셀·구글 폼·카카오톡으로 수기 관리 중.
```

### 자동화 요청사항
```
수강 신청부터 자격증 발급까지 통합된 웹 시스템:
1. 온라인 수강 신청 (1·2·3단계 코스 선택, 회원가입 동시)
2. 결제 (카드·계좌이체·세금계산서 발행)
3. 수강생 대시보드 (본인 진도·강의 일정·자격증 보기)
4. 운영자 관리 페이지 (수강생 목록·출결·문의 응대)
5. 강의 일정 관리 + 화상 링크 자동 발송
6. 자격증 자동 발급 (수료 조건 충족 시 PDF + DB 등록 + 이메일 발송)
```

### 반복 주기
- **주기**: 분기 모집 (연 4회) + 일상 운영 매일
- **예상 소요시간**: 3시간/일 (출결·문의·일정 조율)

### 현재 사용 도구
```
엑셀(수강생 관리), 구글 폼(신청), 카카오톡(안내), 인스타그램·블로그(홍보)
```

### 제약·금지
```
운영비 월 $300 이하 (결제 수수료 별도). 한국 결제(국내 카드사·세금계산서) 필수.
CEO 수강생 개인정보 보호 — 일반 보안 + 결제 PCI 준수.
```

## 📦 5. 도구 상세 정보

### 1. Next.js 14
- **카테고리**: 풀스택 프레임워크
- **설명**: React 기반 풀스택 프레임워크. App Router·서버 컴포넌트·API Routes로 프론트와 백엔드를 한 코드베이스에 통합.
- **주요 용도**: SSR·SSG·API Routes·서버 컴포넌트·이미지 최적화·SEO
- **난이도**: intermediate
- **가격 정책**: free (오픈소스, 검색일 2026-05-09 기준)
- **링크**: https://nextjs.org

### 2. Supabase
- **카테고리**: BaaS (Backend-as-a-Service)
- **설명**: PostgreSQL 기반 오픈소스 BaaS. 인증·DB·Storage·Realtime·Edge Functions 통합. Firebase 대안으로 SQL 사용.
- **주요 용도**: 회원 인증, 관계형 DB, 파일 저장, 실시간 구독, RLS 보안
- **난이도**: intermediate
- **가격 정책**: freemium (Free: 500MB DB / Pro: $25/월) (검색일 2026-05-09 기준)
- **링크**: https://supabase.com

### 3. 포트원 (PortOne)
- **카테고리**: 결제
- **설명**: 한국 결제 통합 PG. 신용카드·계좌이체·간편결제·세금계산서 모두 단일 API로 처리. 법인 사업자 등록 후 PG사 심사.
- **주요 용도**: 국내 카드 결제, 계좌이체, 간편결제(카카오페이·네이버페이), 환불, 세금계산서 발행
- **난이도**: intermediate
- **가격 정책**: 가입 무료 + PG 수수료 (카드 약 3.3%, 검색일 2026-05-09 기준)
- **링크**: https://portone.io

### 4. Resend
- **카테고리**: 이메일·알림
- **설명**: 개발자 친화 트랜잭션 이메일 서비스. React Email로 템플릿을 컴포넌트로 작성. SendGrid 대비 단순.
- **주요 용도**: 수강 안내, 자격증 발급 메일, 결제 영수증, 알림 이메일
- **난이도**: beginner
- **가격 정책**: freemium (Free: 100/일·3,000/월 / Pro: $20/월·50,000) (검색일 2026-05-09 기준)
- **링크**: https://resend.com

### 5. Vercel
- **카테고리**: 배포·호스팅
- **설명**: Next.js 제작사가 만든 호스팅 플랫폼. Git push → 자동 배포. CDN + 서버리스 함수 + 무중단 롤백.
- **주요 용도**: Next.js 자동 배포, 프리뷰 환경, 도메인 연결, 환경 변수 관리
- **난이도**: beginner
- **가격 정책**: freemium (Hobby: 무료 / Pro: $20/월) (검색일 2026-05-09 기준)
- **링크**: https://vercel.com

## 📝 6. 자동화 워크플로우

### Step 1: 수강 신청 + 회원가입 + 결제 통합 페이지
- **도구**: Next.js + Supabase Auth + 포트원
- **설명**: 메인 페이지에서 코스(1·2·3단계) 선택 → 회원가입(이메일+비밀번호 또는 카카오 OAuth) → 결제 → 신청 완료. 한 화면 흐름으로 이탈 최소화.
- **예상 결과물**: 신청·결제 데이터가 Supabase DB에 자동 저장된 모집 페이지
- **예상 소요시간**: 초기 개발 1주, 이후 자동 운영

### Step 2: 수강생 대시보드
- **도구**: Next.js (App Router) + Supabase RLS
- **설명**: 로그인한 수강생만 본인 진도·강의 일정·결제 내역·자격증을 볼 수 있는 화면. Row Level Security로 본인 데이터만 노출.
- **예상 결과물**: 수강생 개인 페이지 (진도 그래프, 다음 강의 일시, 자격증 다운로드 버튼)
- **예상 소요시간**: 5분 (페이지 로딩) / 자동

### Step 3: 운영자 관리 페이지
- **도구**: Next.js + Supabase (admin 권한 RLS)
- **설명**: 운영팀(박지훈 팀장 등) 전용 화면. 수강생 목록·검색·출결 입력·문의 응대·환불 처리 모두 한 곳에서.
- **예상 결과물**: 운영자 대시보드 (수강생 통계·출결 표·문의함)
- **예상 소요시간**: 10분/일 (체크 + 응대) — 현재 3시간 → 10분

### Step 4: 강의 일정 + 화상 링크 자동 발송
- **도구**: Next.js cron + Resend + Zoom API
- **설명**: 강의 24시간·1시간 전 자동 알림. 화상 강의는 Zoom API로 미팅 자동 생성 → 링크 이메일 발송.
- **예상 결과물**: 강의 직전 자동 알림 받는 수강생, 운영자는 손 안 댐
- **예상 소요시간**: 자동 (운영자 0분)

### Step 5: 자격증 자동 발급
- **도구**: Next.js + react-pdf + Supabase Storage + Resend
- **설명**: 수료 조건 충족(출석률 80% + 과제 통과) 자동 감지 → PDF 자격증 생성(고유 인증번호 + QR 코드) → Storage 저장 → 수강생 이메일 발송 + DB 발급 이력 기록.
- **예상 결과물**: 자동 발급된 자격증 (위변조 방지 QR 검증 페이지 포함)
- **예상 소요시간**: 자동 (운영자 0분)

## 💡 8. 코칭 팁

1. **결제 시스템부터 단단히 구축하세요**. CEO 수강생 대상이라 결제 실패·환불 응대가 신뢰의 첫 관문. 포트원 테스트 모드에서 카드·계좌이체·세금계산서 전 흐름을 사전 검증하고, 환불 정책을 약관에 명문화한 뒤 오픈하세요.
2. **자동화는 빠르되 응답 톤은 사람 같이**. 자동 발송 메일·알림이라도 "박지훈 팀장 드림" 형태로 발신자 명시 + 따뜻한 문구. CEO들은 영혼 없는 자동 메시지에 민감하므로 톤 다듬기에 ChatGPT API 잠깐 활용해도 좋습니다.
3. **자격증은 위변조 방지가 핵심**. PDF에 고유 발급 번호 + QR 코드 삽입 → QR 스캔 시 공식 검증 페이지로 연결. 수강생이 LinkedIn·이력서에 첨부했을 때 신뢰 확보. 절약된 50시간 중 일부는 검증 페이지 디자인에 투자할 가치 있습니다.
