# 웹자동화 스킬

## 한 줄로

AI에게 만들고 싶은 거 편하게 말씀하시면, **3가지 기획 문서**를 자동으로 만들어드려요.

> 개발 지식은 없어도 됩니다. 단, **Node.js**와 **Claude Code** 2가지 프로그램 설치는 필요합니다 (→ 아래 사전 요구사항 참고).

---

## 무엇을 만들어주나요

[1] **진단 보고서** — 그 일을 어떻게 자동화하면 좋을지 진단 (어떤 도구 써야 좋은지, 시간 얼마나 절약되는지 등)

[2] **설계도** — 만들 시스템 그림 (어떤 화면이 있고, 어떤 기능이 들어가야 하는지)

[3] **개발자용 안내서** — 개발자에게 넘기면 그대로 만들 수 있는 기술 사양서

이 3가지가 한 번에 자동으로 만들어집니다. 보통 5~10분 걸려요.

---

## 누구에게 좋은가요

- **사장님·임원** — 코딩 몰라도 직원·외주에게 정확한 발주 가능
- **AI 강의 수강생** — 배운 거 바로 자기 업무에 적용
- **프리랜서·컨설턴트** — 의뢰인 업무 빠르게 진단·견적
- **개발 시작하는 분** — 막막한 기획 단계를 AI가 대신

## 어떻게 쓰나요

### 1단계 — 준비
컴퓨터에 **Claude Code**와 **Node.js**가 설치돼 있어야 해요. (아래 사전 요구사항 참고)

### 2단계 — 이 폴더 복사하기

이 `웹자동화` 폴더 전체를 아래 위치에 복사하세요:
- **윈도우**: `C:\Users\사용자이름\.claude\skills\웹자동화\`
- **맥/리눅스**: `~/.claude/skills/웹자동화/`

git을 쓰신다면:
```
git clone https://github.com/bdjsoro-optimus/web-auto ~/.claude/skills/웹자동화
```

### 3단계 — 시작

> ⚠️ **중요 — Claude Code 재시작 1회 필요**
>
> 설치 후 Claude Code가 켜져있다면 **반드시 종료 후 다시 시작**해주세요.
> 이미 시작된 Claude Code 세션은 새로 깐 스킬을 인식하지 못합니다.
> (마켓플레이스 플러그인 설치와 달리, 파일 복사 방식은 reload 신호가 없어서 그래요)

재시작 후 Claude Code 열고 다음 중 한 마디 하세요:
- "자동화 시스템 만들어 줘"
- "처음부터 시작하자"
- 또는 그냥 `/웹자동화`

이후 AI가 묻는 말에 편하게 답하시면 됩니다. 어려운 단어 안 써요.

## AI가 어떻게 일하나요

```
당신: "수강생 관리 시스템 만들고 싶어"
   ↓
AI: 어떤 일이고 어떻게 자동화할지 친근하게 인터뷰
   → 진단 보고서.md 자동 저장 ✅
   ↓
AI: 그 내용으로 설계도 작성
   → 설계도.md 자동 저장 ✅
   ↓
AI: 그 설계대로 만드는 데 필요한 기술 사양 작성
   → 개발자용 안내서.md 자동 저장 ✅
   ↓
AI: 5가지 품질 검사 자동 실행 (형식 오류·누락 항목 등)
   → 문제 있으면 자동 보완 후 재검증
   ↓
AI: 의미 검증 자동 실행 (설계 결정이 지침서에 제대로 반영됐는지)
   → 문제 있으면 자동 보완 후 재검증
   ↓
AI: 구현 가능성 채점 자동 실행 (개발자가 바로 착수할 수 있는 수준인지 100점 만점)
   → 100점 미만이면 부족한 부분 자동 보완 후 재채점
   ↓
AI: 다 됐어요. 파일 위치 알려드릴게요.
```

## 자주 묻는 질문

**Q. 무료인가요?**
A. 스킬 자체는 무료. Claude Code 사용료(Anthropic 요금)는 별도예요. 무료 티어로도 작동합니다.

**Q. 인터넷 있어야 하나요?**
A. 네, AI가 최신 정보 검색하는 데 필요해요.

**Q. 중간에 멈추고 싶으면?**
A. "잠깐"·"멈춰" 라고만 하세요. "계속"이라 하면 다시 시작.

**Q. 같은 작업 다시 하고 싶으면?**
A. 그냥 다시 시작하세요. 기존 파일 있으면 AI가 "이어서? 새로?" 물어봐요.

**Q. 답하기 어려운 질문 나오면?**
A. "잘 모르겠어"라고 답하시면 AI가 알아서 적당한 디폴트로 채우고, 나중에 [AI가 정함] 표시로 어디 채웠는지 알려드려요.
